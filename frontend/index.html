❓ Aide — Prise en main d'HCOSMO

1. Créer un projet
Cliquez sur "Voir le plan 2D", choisissez un outil dans la barre (Dalle, Mur, Poteau, Fenêtre, Porte, Toit...) puis cliquez sur le plan pour poser vos éléments. Le plateau démarre toujours vide — à vous de construire.

2. Régler les dimensions
Les tailles par défaut (hauteur de mur, épaisseur, matériau...) se règlent dans le panneau ⚙️ avant de dessiner. Chaque élément posé reste ensuite modifiable individuellement dans le panneau 📋.

3. Enregistrer votre projet
Bouton "💾 Exporter le projet" : télécharge un fichier .hcosmo contenant tout votre projet.

4. Ouvrir un projet existant
Bouton "📂 Ouvrir un projet" : sélectionnez un fichier .hcosmo précédemment enregistré pour reprendre où vous en étiez.

5. Visualiser
"🎯 Cadrer" recentre la caméra sur tout ce que vous avez construit. Basculez entre la vue 3D et le plan 2D avec le bouton en haut à droite.

6. Raccourcis clavier
Ctrl + Z — annuler la dernière action
Ctrl + Y (ou Ctrl + Maj + Z) — rétablir
Ctrl + D — duplique l'élément sélectionné (mur, dalle, poteau ou toit)
Maj maintenue pendant le tracé d'un mur — accroche l'angle à 45°
Échap — quitte l'outil de dessin en cours, ou ferme la fenêtre ouverte
Entrée — valide le nom dans la fenêtre "Nouveau projet"
